DROP YOUR PHOTOS IN THIS FOLDER
================================

The site looks for three images by these exact names. Until a file exists,
a dashed placeholder shows in its spot — so you can deploy first and add
photos later.

  images/dan-hero.jpg       Portrait   ~800 x 1000px   (main hero headshot)
  images/dan-about.jpg      Landscape  ~1000 x 800px   (you at work / desk)
  images/dan-lifestyle.jpg  Portrait   ~800 x 1000px   (golf, family or coast)

Tips:
- Keep each file under ~400KB so the page stays fast (export as JPG, quality ~80).
- .jpg is expected. If you'd rather use .png or .webp, change the src in index.html.
- Square-ish crops work fine too; images are centre-cropped to fit.
